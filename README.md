# Vem pra Quadra · Érica Messias

Sistema de presença, pagamentos e rotina das aulas de ginástica.

- **Marca:** Érica Messias · Professora de Educação Física · Vem pra Quadra
- **Aulas:** quarta e sexta, 05:00 e 19:00
- **Mensalidade padrão:** R$ 50,00
- Dados salvos no navegador (`localStorage`). Nada é enviado para servidor.

## Arquivos

| Arquivo | Função |
|---|---|
| `index.html` | Página do sistema (logo embutida) |
| `styles.css` | Tema azul da marca |
| `script.js` | Presença, pagamentos, relatórios e rotina |

## Uso

Abra `index.html` no navegador ou acesse pelo GitHub Pages.

Site: https://jmessias1984-hue.github.io/vempraquadra/
